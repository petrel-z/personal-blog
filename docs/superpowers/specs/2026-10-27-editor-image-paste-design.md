# 文章所见即所得编辑器设计

用户在 2026-10-28 明确选择：改为所见即所得编辑器，编辑时直接显示图片。本设计替代之前的 Markdown 源码编辑方案。

## 目标与行为

正文默认所见即所得，图片、标题、列表、表格和代码可直接查看和编辑。复制图片后粘贴到光标处立即出现本地上传预览，上传成功换成正式地址；拖放与选择文件也支持插图。上传期间可以继续输入，插入位置随文档变更移动；失败显示错误并移除临时图片，不丢正文。支持多图。

## 方案

已讨论保留 Markdown 输入、并排预览、所见即所得三种方案，用户选择第三种。实现采用 Milkdown/ProseMirror 的 Markdown 编辑基础，保存仍为 Markdown，继续复用 `/api/upload`，兼容既有文章前台和草稿格式。保留源码入口和已有预览，以处理特殊 Markdown/HTML。没有持久化图片前阻止保存，临时 blob URL 不进入 Markdown/草稿；上传大小与格式使用现有 JPG/PNG/GIF/WebP、5MB 约束。

## 实现边界

替换正文输入组件并加入基础格式工具栏、图片上传状态。标题、文章设置、封面、权限和草稿行为沿用现有逻辑；不修改数据库格式。默认所见即所得，源码/预览切换保留当前内容；对特殊语法保留原文，避免无编辑时规范化导致脏状态或数据丢失。

## 验证

自动化覆盖真实编辑器的 Markdown 读取/输出、剪贴板图片显示在前后文字之间、上传时继续输入、删除上传位置、多图、失败/重试、撤销、只读、草稿恢复和保存重载。类型检查和原有 Jest 测试必须运行；桌面与手机宽度检查布局。
